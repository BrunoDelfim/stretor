Três iframes, o mesmo episódio. No superflix, o painel mostra a tela "Verificação" e não vai além dela: o widget Turnstile em contexto de terceiro não completa, e é por isso que existe a seção passe do Cloudflare abaixo — o desafio se vence numa aba de verdade, e o que ela ganha é o que o backend precisa para abrir a página do episódio.

O painel do episódio não libera o backend: iframe em contexto de terceiro não completa o Turnstile, e o FlareSolverr devolve a mesma tela de verificação (Challenge not detected! no log dele). Quem vence o widget é uma aba de verdade — abrir em aba ↗, passar a verificação e trazer o que ela ganhou. Vale 45 minutos, o prazo que o host anuncia na própria resposta.

São dois portões, não um. O desta seção é a Verificação (o Turnstile do Cloudflare). A tela Acesso Restrito · Visualização Externa é outra coisa: é o anti-hotlink do site, que aparece quando o pedido chega com Referer de fora — é o que a aba aberta por um link daqui veria. O link acima vai sem Referer de propósito, e assim se comporta como o backend (que também não manda nenhum).

Como copiar o passe. Na aba já liberada, F12 → Network → o pedido do episódio (o documento, Doc) → botão direito → Copy → Copy as cURL. Cole o bloco inteiro no campo do cookie: o backend recorta a linha cookie: e reenvia todos os cookies da sessão, com os nomes. Colar só o valor do cf_clearance (Application → Cookies → duas vezes na célula) também serve, mas aí o backend não sabe de mais nada — e um token sem nome não é cookie: se o que você tem é um token solto, o campo dele é o cfv. O agente já vem preenchido com o desta aba: o passe só vale para o par IP + agente que venceu o widget, e o host recusa o par trocado devolvendo a mesma tela de verificação, sem dizer por quê.

Cuidado com o atalho do console. O host marca o cf_clearance como HttpOnly: rodar document.cookie na aba devolve os outros cookies e não devolve este. Colar essa lista preenche o campo sem entregar passe nenhum, e a conferência mostra isso na lista (traz: …) — sem o cf_clearance entre os nomes. Para copiar de verdade, use o cabeçalho cookie: do pedido (Copy as cURL) ou a linha em Application → Cookies.

Conferir na hora. O passe guardado não prova nada sozinho: o host recusa o par IP + agente trocado devolvendo a mesma tela de verificação de quem não apresentou nada. Este botão faz o backend pedir a página de verdade, com o passe anexado, e diz o que voltou — a verificação ou o episódio —, junto do carimbo do valor e do IP por onde o backend sai.
